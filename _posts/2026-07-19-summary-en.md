The Trump administration is considering creating an independent AI oversight body modeled after the Financial Industry Regulatory Authority (FINRA) to review the safety of top AI models before release. The proposal, led by Treasury Secretary Scott Bessent, is currently under review by White House Chief of Staff Susie Wiles. This marks a groundbreaking shift toward formal, independent AI regulation in the U.S., addressing both Wall Street's cybersecurity concerns and Silicon Valley's dissatisfaction with temporary government controls. If enacted, it could give industry stakeholders more influence in setting safety standards and reshape the global AI governance landscape. The proposed agency would report to the Securities and Exchange Commission (SEC), similar to FINRA's structure. The plan aligns with a suggestion from Google DeepMind CEO Demis Hassabis for an industry-funded independent regulator, and comes after Anthropic and OpenAI objected to government demands to modify or restrict their latest models.

It can aid researchers and practitioners in debugging, analyzing biases, and improving language models. The visualization uses t-SNE on a compressed representation of the embedding table, with edges representing a minimum spanning tree to show real nearest-kin relationships. ## [SQLite Query Explainer: Interactive Web Tool](https://simonwillison.net/2026/Jul/18/sqlite-query-explainer/#atom-everything) ⭐️ 7.0/10

Simon Willison released an interactive web tool that runs SQLite in the browser via Pyodide and WebAssembly to explain SQLite query plans, inspired by Julia Evans' blog post. This tool makes SQLite query plan analysis accessible to developers who find EXPLAIN output cryptic, potentially improving database performance understanding across the community. The tool runs Python inside Pyodide (CPython ported to WebAssembly) in the browser, executing SQLite's EXPLAIN and EXPLAIN QUERY PLAN commands and adding explanatory annotations. The author cautions that he is not fully confident in the correctness of the explanations.

rss · Simon Willison · Jul 18, 17:19

**Background**: SQLite's EXPLAIN QUERY PLAN command outputs a high-level description of how a query is executed, but its output can be difficult to interpret without deep knowledge. Pyodide is a Python distribution for the browser based on WebAssembly, enabling Python code to run client-side without a server. WebAssembly is a binary instruction format that allows high-performance execution in web browsers.
