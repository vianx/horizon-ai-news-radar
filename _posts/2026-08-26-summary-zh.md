## [FDA 批准首款同时监测酮体和血糖的可穿戴设备](https://www.fda.gov/news-events/press-announcements/fda-authorizes-first-wearable-device-continuously-monitors-both-ketone-levels-and-blood-sugar) ⭐️ 8.0/10

美国 FDA 已批准首款在美国连续监测酮体和血糖的可穿戴设备——Libre Duo 10 Day。这也是全球首款在同一设备中同时监测这两项指标的产品。 此次批准可能通过提供血糖和酮体的实时数据，显著改善糖尿病管理，帮助预防糖尿病酮症酸中毒等危险状况。这也可能为更集成的可穿戴健康监测设备铺平道路。 该设备名为 Libre Duo 10 Day，设计佩戴时长为 10 天。它采用连续血糖监测技术，并增加了酮体监测功能，这对有酮症酸中毒风险的 1 型糖尿病患者尤其有用。

hackernews · sunnynagra · 8月25日 19:07 · [社区讨论](https://news.ycombinator.com/item?id=49439017)

**背景**: 连续血糖监测仪（CGM）是可穿戴传感器，可实时追踪血糖水平，帮助糖尿病患者管理病情。酮体是身体分解脂肪供能时产生的物质，水平过高可能表明出现糖尿病酮症酸中毒等严重并发症。此前，酮体监测需要单独的设备或指尖采血测试，对患者来说不够方便。

## [苹果发布 M6 和 M5 Ultra 芯片，性能与 AI 能力大幅提升](https://www.apple.com/newsroom/2026/08/apple-introduces-m6-and-m5-ultra-for-a-big-leap-in-performance-and-ai-compute/) ⭐️ 8.0/10

苹果于 2026 年 8 月 25 日发布了 M6 和 M5 Ultra 芯片，标志着性能和 AI 计算能力的重大飞跃。M6 是苹果首款 2nm 芯片，配备 12 核 CPU、12 核 GPU 和双 16 核神经引擎，而 M5 Ultra 是苹果首款四芯片架构，也是其有史以来最强大的芯片。 这一发布意义重大，代表了苹果芯片的跨代飞跃，M6 的 2nm 工艺和增强的 AI 能力使苹果在 AI 驱动的计算市场中更具竞争力。新芯片将为未来的 Mac 提供动力，可能影响消费者的选择以及行业向更强大、更高效、更专注于 AI 的硬件发展的趋势。 M6 配备了更大的 12 核 CPU，拥有全球最快的 CPU 核心，12 核 GPU 带有神经加速器，统一内存带宽高达 170GB/s。M5 Ultra 则包含 32 核神经引擎和更强大的媒体引擎，支持同时播放多达 33 路 8K ProRes 422 视频（30fps）。

hackernews · interpol_p · 8月25日 13:01 · [社区讨论](https://news.ycombinator.com/item?id=49433292)

**背景**: Apple silicon 是苹果为 Mac 和 iPad 设计的基于 ARM 架构的系统级芯片（SoC）系列，集成了 CPU、GPU 和神经处理单元。M6 和 M5 Ultra 延续了这一传统，其中 M6 是首款采用 2nm 制造工艺的芯片，提供了更好的性能和能效。这些芯片预计将率先出现在更新的 Mac mini 和 Mac Studio 机型中，延续了以往 M 系列芯片的发布模式。

## [OpenAI 自研芯片 Jalapeño 在推理测试中超越英伟达 Blackwell](https://newsletter.semianalysis.com/p/openai-jalapeno-better-than-nvidia) ⭐️ 8.0/10

OpenAI 公布了与博通合作开发的自研推理芯片 Jalapeño 的首批基准测试结果。该芯片在单位功耗的 AI 工作量上比英伟达 GB300（Blackwell Ultra）高 1.5 至 1.9 倍，端到端延迟低 1.7 至 3.6 倍，高交互场景性能高 2.1 至 4.1 倍。 这标志着 AI 硬件领域的一个重要里程碑，因为一家主要的 AI 实验室开发出了挑战英伟达在推理领域主导地位的芯片。这可能会带来更多竞争、降低成本，并推动针对 AI 工作负载的专用设计，可能重塑 AI 基础设施格局。 Jalapeño 采用类似英伟达 NVL72 的机架级架构，每个机架配备 128 个加速器，每个加速器在 MXFP4 精度下可提供 13.4 petaFLOPS 算力。芯片额定功耗为 700 瓦，但持续功耗低于 550 瓦。该芯片仅用于推理，不用于训练，且未与英伟达即将推出的 Vera Rubin 进行比较。

hackernews · bmulholland · 8月25日 14:06 · [社区讨论](https://news.ycombinator.com/item?id=49434378)

**背景**: AI 推理硬件对于高效部署大型语言模型至关重要。英伟达的 Blackwell 架构一直是行业标准，但像 Jalapeño 这样的定制芯片旨在针对特定工作负载进行优化，减少数据移动并提高利用率。OpenAI 计划在今年年底前在其自有数据中心部署 Jalapeño，第二代已在开发中，第三代正在设计。

## [EVE Online 开始从 Stackless Python 2.7 迁移至 Python 3](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online 宣布开始从 Stackless Python 2.7 迁移至 Python 3，使用 futurize 脚本处理 240 万行代码，并手动审查约 2 万个行为差异。 此次迁移意义重大，因为它展示了一种升级大型、长期运行的 Python 代码库的策略，为其他仍在使用 Python 2 的大型项目提供了借鉴。同时，它也凸显了从已停产的 Stackless Python 迁移的挑战。 此次迁移涉及 240 万行代码和约 2 万个 Python 2 与 3 行为差异之处，例如整数除法。公告未说明如何替换 Stackless，但此前会议演讲描述了在 EVE Frontier 中使用 carbonengine/scheduler 库。

rss · Simon Willison · 8月25日 22:59

**背景**: Stackless Python 是 Python 的一个变体，提供微线程（tasklets）以实现轻量级并发，但其 GitHub 仓库已于 2025 年 2 月归档，项目已停止维护。python-future 项目中的 futurize 脚本可自动将 Python 2 代码转换为兼容 Python 3，但需要手动审查细微的行为变化。
