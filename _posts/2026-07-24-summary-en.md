## [PyPI Blocks New File Uploads to Old Releases After 14 Days](https://simonwillison.net/2026/Jul/23/seth-larson/#atom-everything) ⭐️ 8.0/10

PyPI now rejects new file uploads to releases older than 14 days, a change implemented to prevent supply-chain attacks via compromised tokens or workflows. This closes a significant security gap in the Python ecosystem, making it harder for attackers to poison long-stable releases even if they gain access to publishing credentials. The restriction was implemented via pull request #19727 on the PyPI Warehouse repository, and as of the announcement, no known abuse had occurred.

rss · Simon Willison · Jul 23, 04:50

**Background**: PyPI is the official third-party software repository for Python. Supply-chain attacks on package registries have become increasingly common, where attackers upload malicious files to legitimate packages to infect downstream users. This measure prevents attackers from adding malicious files to old, trusted releases even if they compromise a project's publishing tokens or CI/CD workflows.
