## [FDA Approves First Wearable for Continuous Ketone and Glucose Monitoring](https://www.fda.gov/news-events/press-announcements/fda-authorizes-first-wearable-device-continuously-monitors-both-ketone-levels-and-blood-sugar) ⭐️ 8.0/10

The U.S. Food and Drug Administration (FDA) has authorized the Libre Duo 10 Day Continuous Dual Glucose Ketone Monitoring System, the first wearable device that continuously monitors both ketone levels and blood sugar, for people aged 2 years and older with diabetes. This milestone could significantly improve diabetes management by enabling early detection of diabetic ketoacidosis (DKA), a life-threatening condition. It also paves the way for more integrated wearable health monitoring, potentially benefiting millions of people with diabetes and advancing personalized medicine. The device is based on Abbott's FreeStyle Libre 3 sensor, known for being the world's smallest and thinnest continuous glucose monitor (CGM). It received breakthrough device designation from the FDA during development, and the authorization covers use in people aged 2 years and older.

hackernews · sunnynagra · Aug 25, 19:07 · [Discussion](https://news.ycombinator.com/item?id=49439017)

**Background**: Continuous glucose monitors (CGMs) are small wearable sensors that measure glucose levels in interstitial fluid, providing real-time data to help manage diabetes. Ketones are chemicals produced by the liver when the body breaks down fat for energy; dangerously high levels can lead to diabetic ketoacidosis (DKA), a serious complication. Previously, no device could continuously monitor both metrics simultaneously, and ketone testing typically required fingerstick blood tests or urine strips.

## [OpenAI's Jalapeño Chip Outperforms Nvidia Blackwell in Inference](https://newsletter.semianalysis.com/p/openai-jalapeno-better-than-nvidia) ⭐️ 8.0/10

OpenAI has unveiled its first custom inference chip, Jalapeño, co-designed with Broadcom, and released benchmark data showing it outperforms Nvidia's GB300 (Blackwell) in energy efficiency and latency. The chip achieves 1.5 to 1.9 times more AI work per watt, 1.7 to 3.6 times lower end-to-end latency, and 2.1 to 4.1 times higher performance in high-interaction scenarios across models like GPT-OSS 120B, DeepSeek R1 670B, and Kimi K2.5 1T. This marks a significant move by OpenAI to reduce its dependence on Nvidia for AI inference, potentially reshaping the AI hardware landscape. If Jalapeño delivers on its claims, it could accelerate the trend toward custom silicon and drive down inference costs, impacting cloud providers, AI startups, and the broader GPU market. The chip has a rated power of 700W but sustains no more than 550W in real-world use. It was benchmarked against Nvidia's GB300, not the newer Vera Rubin, and is not intended for model training. OpenAI plans to deploy Jalapeño in its own data centers by the end of the year, with a second generation in development and a third in design.

**Background**: AI inference hardware is the specialized computing infrastructure used to run trained AI models on new data, as opposed to training hardware. OpenAI's move to design custom chips with Broadcom reflects a broader industry trend where major AI companies seek to optimize performance and cost by tailoring silicon to their specific workloads.

## [EVE Online Begins Migration from Python 2.7 to Python 3](https://simonwillison.net/2026/Aug/25/eve-online-move-to-python-3/) ⭐️ 8.0/10

EVE Online has announced the start of its migration from Stackless Python 2.7 to Python 3, using the futurize script on 2.4 million lines of code, followed by manual review of approximately 20,000 places where Python 2 and 3 behavior differ. This migration is significant because EVE Online is one of the largest and longest-running Python codebases in production, and its move to Python 3 marks a major milestone for the Python community. It also highlights the challenges and strategies for migrating large-scale legacy Python systems, which many organizations still face. The migration will use the futurize script, which automatically converts Python 2 code to a Python 2/3 compatible codebase, followed by manual review of about 20,000 places where behavior differs, such as integer division. The announcement does not specify how they will replace Stackless Python, but a previous presentation described using the open-source carbonengine/scheduler library for their newer game EVE Frontier.

rss · Simon Willison · Aug 25, 22:59

**Background**: EVE Online has been running on Stackless Python since its launch in 2003, and its last major upgrade was to Stackless Python 2.7 in 2010. Stackless Python is a variant of Python that provides microthreads (tasklets) for lightweight concurrency, but it has been officially discontinued and its GitHub repository archived since February 2025. The futurize script is part of the python-future project, which helps migrate Python 2 code to Python 3 while maintaining compatibility with Python 2.
